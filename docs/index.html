Curfew Bot — Pannello

Funziona interamente dal browser, senza server: le modifiche si salvano direttamente su GitHub, e il bot (che gira gratis su GitHub Actions ogni ~15 minuti) le applica da solo.

Accesso

Se dopo un salvataggio i gruppi sembrano spariti, clicca "🕐 Versioni precedenti": ogni salvataggio resta sempre recuperabile da lì, puoi ripristinarlo da sola in autonomia, senza bisogno d'aiuto.
Il token GitHub serve solo per leggere/scrivere config/curfew-config.json in questo repository. Si crea una volta sola su GitHub: Impostazioni account → Developer settings → Personal access tokens → Fine-grained tokens → scegli questo repository → permesso "Contents: Read and write". Entrambi i token restano salvati solo su questo telefono/browser.
Nessuna modifica da salvare.

Gruppi

Per trovare il chat_id di un nuovo gruppo: aggiungi il bot al gruppo, scrivi un messaggio qualsiasi, poi premi "Recupera Chat ID". Il link d'invito t.me/+... NON è il chat_id.
